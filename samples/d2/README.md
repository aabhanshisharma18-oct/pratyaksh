# D2 generated samples

Run `python -m backend.d2.samples.generate` from the repository root. The seeded generator creates an unedited control, an exact copy-move image and mask, a repeating-texture limitation case, corrupt and unsupported inputs, an MJPEG video with a documented duplicated frame pair, and `evaluation-report.json`. Generated media is intentionally small and must not be presented as a statistical accuracy study.
